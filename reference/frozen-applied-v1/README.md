# Frozen applied-v1 source files

This folder preserves the two Markdown source files used to define and support the Health Data Readiness Level (HDRL) Framework v1.0 during the 3 Nations Readiness Assessment.

The files have been moved here from the repository root without changing their content. Their original development-stage terminology is intentionally preserved for reproducibility. The public website provides the current explanation of HDRL's intended use, validation status, relationship to the UK Health Data Research Service (HDRS), and responsible reuse.
