# Frozen applied-v1 method source

This folder preserves a faithful Markdown transcription of **Annex A: HDRL Framework v1.0 and Methodology**, the final method paper used for the 3 Nations Readiness Assessment.

The transcription was generated from the final DOCX with tracked insertions accepted. Markdown formatting replaces Word formatting, but the framework wording, classifications, indicators, maturity descriptors and method have not been revised. The earlier domain-reference-table file was removed because it was a redundant subset of the complete method paper. The public website provides the current explanation of HDRL's intended use, validation status, relationship to the UK Health Data Research Service (HDRS), and responsible reuse.
